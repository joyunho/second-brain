# 💎 영구 노트 — 내 생각

> 책에서 밑줄 친 문장은 아직 남의 것. 내 말로 다시 쓰고, 다른 생각과 **두 번 이상 연결**되어야 내 뉴런이 된다.
> 그래프에서 가장 촘촘하게 얽혀야 하는 영역. 영구 노트는 `source: "[[문헌 노트]]"`로 [[문헌]]에서 오고, `area`로 [[분야]]에 매달린다.

```dataviewjs
const n = dv.current().file.inlinks.length;
const all = dv.pages('"90_영구"').where(p => p.type === "영구").length;
dv.paragraph(`영구 노트 **${all}**개 · 이 허브를 가리키는 노트 **${n}**개` + (n > 200 ? `\n\n> [!warning] 허브가 너무 커졌어요\n> 영구 노트가 200개를 넘었습니다. 그래프에서 이 허브가 거대한 별이 되지 않게 tpl-idea의 \`up\`을 빼고, 분야(\`area\`)와 출처(\`source\`) 링크만 남기는 것을 고려하세요.` : ""));
```

## 최근 영구 노트
```dataview
TABLE WITHOUT ID file.link AS "영구 노트", source AS "출처", area AS "분야", length(file.outlinks) AS "연결", file.cday AS "날짜"
FROM "90_영구"
WHERE type = "영구"
SORT file.cday DESC
LIMIT 20
```

## 🔗 연결이 약한 뉴런 (링크 3개 이하 — 이어 주세요)
```dataview
TABLE WITHOUT ID file.link AS "영구 노트", length(file.outlinks) + length(file.inlinks) AS "연결 수", source AS "출처"
FROM "90_영구"
WHERE type = "영구" AND (length(file.outlinks) + length(file.inlinks)) <= 3
SORT file.cday ASC
```

## 🌟 가장 많이 연결된 뉴런
```dataview
TABLE WITHOUT ID file.link AS "영구 노트", length(file.inlinks) AS "들어오는 링크", area AS "분야"
FROM "90_영구"
WHERE type = "영구"
SORT length(file.inlinks) DESC
LIMIT 10
```

## 📚 출처별
```dataview
TABLE WITHOUT ID source AS "출처", length(rows) AS "영구 노트", rows.file.link AS "목록"
FROM "90_영구"
WHERE type = "영구" AND source
GROUP BY source
SORT length(rows) DESC
LIMIT 15
```

## 쓰는 법
- 한 노트 = 한 생각. 제목은 **문장**으로 ("습관은 보상이 아니라 신호로 시작된다").
- `Ctrl/Cmd+N` → 💎 영구 노트, 또는 Inbox 노트에 `#영구`.
- `source`에 출처 책/글/자료를 `[[ ]]`로. 그러면 문헌 → 영구 노트 선이 그어진다. 일기에서 나온 생각이면 일기 노트의 `## 생각 · 연결`에서 링크한다.
- 연결은 최소 2개. 부족한 노트는 위 "연결이 약한 뉴런"과 [[Health]]에 뜬다.
