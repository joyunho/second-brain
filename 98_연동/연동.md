# 🔌 연동 — 외부 입력

> 다른 앱에 흩어진 것을 이 뇌로 끌어오는 **입력 신경**. 폰 · 음성 · 사진 캡처는 YouKnow 앱이 맡고, 손글씨는 GoodNotes, 일정은 Google Calendar가 맡는다. 세부 설정 절차는 저장소 루트 `README.md`.

## 📲 YouKnow
- **상태 노트**: [[YouKnow]] — 앱 설정(사이트 이름 · 기분 · 태그 · 종류), 기능 플래그(V10~V17), 마지막 가져오기 로그, 휴지통 · 사라진 행 · 채택 실패 목록. `import_youknow.py`가 실행마다 다시 쓴다.
- **흐름**: 폰에서 YouKnow에 적는다(Siri `/api/capture`, Scriptable 위젯, 사진 업로드) → 매일 23:30 `import_youknow.py --supabase` → 볼트의 일간 · 일기 · 할 일 · 프로젝트 · 자료 · 습관 · 일과 노트 → Obsidian Git 커밋. 멱등이고, `%% yk:… %%` 블록 밖의 내 글은 건드리지 않는다.
- **역방향**: 일기는 `--export-diaries-for-youknow <폴더>`가 앱의 ".md 일기 가져오기" 형식으로 써 준다. 할 일은 `_System/Templates/tpl-inbox.md` 첫머리의 `PUSH_TO_YOUKNOW = true`(+ `YK_CAPTURE_KEY`)를 켜면 ⚡ 원문이 앱 `/api/capture`에도 들어간다(Vercel에 `WIDGET_KEY` 설정 필요). 앱 id를 못 받은 노트는 `yk_pending: true`로 남고 야간 가져오기가 (제목·마감·만든 날 ±1일)로 채택하거나 `--push-pending`으로 재전송한다. 상태 변경 · 습관 체크 해제는 아래 "YouKnow에 반영 필요" 목록을 보고 앱에서 손으로 반영한다.

```dataviewjs
const yk = dv.page("98_연동/YouKnow");
if (!yk) dv.paragraph("> 아직 가져온 적이 없어요. 아래 명령 중 하나를 실행하면 [[YouKnow]] 노트가 생깁니다.");
else {
  // counts: importer는 ["tasks 12", "daily_logs 40", …] 리스트로 쓴다 (객체·문자열도 허용)
  const c = yk.counts ?? [];
  const counts = Array.isArray(c) ? c.map(String).join(" · ")
    : (c && typeof c === "object" && !c.toFormat) ? Object.entries(c).map(([k, v]) => `${k} ${v}`).join(" · ") : String(c);
  const li = yk.last_import; const when = !li ? "—" : li.toFormat ? li.toFormat("yyyy-MM-dd HH:mm") : String(li).replace("T", " ").slice(0, 16);
  dv.paragraph(`마지막 가져오기 **${when}** · 소스 **${yk.source ?? "—"}** · 사이트 **${yk.site_name ?? "—"}**` + (counts ? `\n\n${counts}` : ""));
}
```

### 가져오기 3가지 모드
```bash
cd <볼트 경로>
# ① 권장 — Supabase REST (12테이블 전부 + 휴지통 + 사진). _System/Scripts/.env 에 YK_SUPABASE_URL · YK_SUPABASE_ANON_KEY (· YK_OWNER_ID)
python3 -I _System/Scripts/import_youknow.py --supabase --dry-run     # 먼저 미리보기
python3 -I _System/Scripts/import_youknow.py --supabase
# ② 앱 설정 → 데이터 · 백업 → "전체 백업(.json)" (8테이블; 습관 · 습관 체크 · 일과 · 하루 계획 · 사진은 없음)
python3 -I _System/Scripts/import_youknow.py --backup "98_연동/YouKnow/백업/youknow-backup-2026-10-16.json"
# ③ 앱 "마크다운 볼트 내보내기(.zip)" — 일기만 (fallback)
python3 -I _System/Scripts/import_youknow.py --zip ~/Downloads/youknow-obsidian-2026-10-16.zip
# 역방향: 앱에 없는 일기를 앱 형식으로 써 주기 → 앱 설정 → 데이터 → ".md 일기 가져오기"
python3 -I _System/Scripts/import_youknow.py --export-diaries-for-youknow ~/Desktop/to-youknow/
```
옵션: `--tz Asia/Seoul` · `--since YYYY-MM-DD`(일간 스켈레톤 하한) · `--no-fill-days` · `--no-photos` · `--push-pending`(`yk_pending` 노트를 앱 `/api/capture`로 재전송). CSV(`youknow-tasks-*.csv`)와 `calendar.ics`는 id가 없어 가져오지 않는다.

### ⚠️ YouKnow에 반영 필요 (`yk_dirty`)
> 볼트에서 바꿨지만 앱에는 없는 변경 — 할 일 상태를 더 진행시켰거나, 습관 체크 · 하루 계획을 옵시디언에서 고친 경우. 앱에서 같은 값으로 바꾼 뒤 속성 `yk_dirty`를 지우면 다음 가져오기에서 사라진다.
```dataview
TABLE WITHOUT ID file.link AS "노트", type AS "유형", status AS "볼트 상태", yk_updated AS "앱 마지막 수정", file.mtime AS "볼트 수정"
FROM -"_System"
WHERE yk_dirty = true
SORT file.mtime DESC
```

### 🗑️ 휴지통 (`yk_deleted`)
```dataview

FROM -"_System"

SORT yk_deleted DESC
```

### 👻 사라진 행 (`yk_missing`) — 앱에서 완전 삭제됨

### ⏳ 앱 id 대기 (`yk_pending`) — 볼트에서 먼저 만든 노트

## ✍️ GoodNotes 5
- 흐름: GoodNotes `자동 백업(PDF)` → 클라우드 폴더 → `_System/Scripts/import_goodnotes.py` → `80_문헌/굿노트/<노트북>.md`(PDF 임베드 + 속성), PDF는 `_Attachments/GoodNotes/`.
- 생성된 노트에는 손글씨 핵심만 텍스트로 옮겨 적고, 관련 책 · 영구 노트와 링크한다. `area`로 분야에 매단다.
```dataview
TABLE WITHOUT ID file.link AS "노트북", file.cday AS "가져온 날", area AS "분야", length(file.outlinks) AS "연결"
FROM "80_문헌/굿노트"
WHERE type = "굿노트"
SORT file.cday DESC
```

## 🗓️ Google Calendar
- 흐름: Google Calendar `비공개 iCal 주소` → **ICS 플러그인** → 일간 노트 `### 캘린더`에 자동 삽입(tpl-daily). 캘린더 자체를 볼트에 저장하지는 않는다 — 일간 노트가 그날의 스냅샷.
- YouKnow 앱의 Google 계정 연동 일정은 서버 세션 전용이라 가져오기 대상이 아니다. 같은 캘린더를 ICS로 직접 읽는다.
- 선택: YouKnow `/api/calendar.ics?type=tasks|diary`를 ICS에 추가하면 📌 마감 · 📔 일기가 종일 일정으로 뜨지만 `import_youknow.py`와 중복이므로 둘 중 하나만.
- 양방향(옵시디언에서 일정 만들기)이 필요해지면 `Google Calendar` 플러그인(OAuth)으로 승격.

## ⏰ 자동화
- `launchd`/`cron`: `30 23 * * * cd <볼트> && python3 -I _System/Scripts/import_youknow.py --supabase && python3 -I _System/Scripts/import_goodnotes.py` → Obsidian Git 자동 커밋(10분).
- iOS 단축어 "뇌에 추가"(Advanced URI 플러그인): `obsidian://adv-uri?vault=second-brain&filepath=00_Inbox/빠른입력 {{날짜시간}}.md&mode=new&data=%3C%25*%20tR%20%2B%3D%20await%20tp.file.include(%22%5B%5Btpl-inbox%5D%5D%22)%20%25%3E%0A{{텍스트}}` → `data`가 Templater 명령 줄(`tp.file.include`로 tpl-inbox 템플릿을 불러오는 Templater 한 줄(위 URL의 `data=` 앞부분을 디코딩한 것), URL 인코딩)로 시작해야 한다 — 폴더 템플릿은 빈 파일에만 적용되므로 이 줄이 tpl-inbox를 실행시키고, 파일명이 `빠른입력`으로 시작하면 메뉴 없이 `capture.js`로 바로 쪼갠다. `{{텍스트}}`는 단축어에서 URL 인코딩.
- 비밀값은 `_System/Scripts/.env`에만(.gitignore). 백업 JSON(`98_연동/YouKnow/백업/*.json`)과 인덱스 캐시(`.yk_index.json`)도 커밋하지 않는다.
