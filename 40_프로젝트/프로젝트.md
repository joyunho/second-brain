# 🗂️ 프로젝트 — 묶음

> YouKnow `#/projects` 화면. 프로젝트 하나 = `40_프로젝트/<이름>/<이름>.md` folder-note 하나. 그 안에 체크리스트(묶음별), 이 프로젝트의 할 일(Dataview), 자료(`자료/` 하위 노트)가 모인다.
> 상태는 **진행 중 · 계획 · 보류 · 완료**(평문). 그래프에서는 프로젝트가 주황 **중간 연결자**로 할 일 · 자료 · 분야 · 날짜를 잇는다.

```dataviewjs
const t = dv.date("today");
const ds = v => !v ? null : (v.toFormat ? v.toFormat("yyyy-MM-dd") : String(v).slice(0, 10));
const ORDER = ["진행 중", "계획", "보류"];
const EMOJI = s => /(건강|운동|헬스|몸)/.test(s) ? "💪" : /(유튜브|영상|채널)/.test(s) ? "🎬" : /(게임|에임|랭크)/.test(s) ? "🎮" : /(스타일|패션|미용|헤어|옷)/.test(s) ? "💇" : /(공부|학교|시험|영어|독서)/.test(s) ? "📚" : /(돈|재테크|주식|저축|소비)/.test(s) ? "💰" : /(생활|집|방|정리)/.test(s) ? "🏠" : "📁";
const linkName = v => !v ? "" : (v.path ? String(v.path) : String(v).replace(/^\[\[|\]\]$/g, "").split("|")[0]).split("/").pop().replace(/\.md$/, "");
const live = p => !p.yk_deleted && !p.yk_missing;   // 앱 휴지통·사라진 행 제외
const projects = dv.pages('"40_프로젝트"').where(p => p.type === "프로젝트" && live(p)).array();
const tasks = dv.pages('"30_할일/목록"').where(p => p.type === "할일" && live(p)).array();
const md = d => dv.date(d).toFormat("M/d");
const dday = d => { if (!d) return "—"; const n = Math.round(dv.date(d).diff(t, "days").days); return n === 0 ? "오늘" : n > 0 ? `D-${n}` : `D+${-n}`; };
const stats = p => {
  const mine = tasks.filter(q => linkName(q.project) === p.file.name);
  const checks = ((p.file.tasks ?? []).array ? p.file.tasks.array() : (p.file.tasks ?? [])).filter(c => String(c.text ?? "").trim());  // 빈 `- [ ] ` 자리표시는 제외
  const done = checks.filter(c => c.completed).length + mine.filter(q => q.status === "완료").length;
  const total = checks.length + mine.filter(q => q.status !== "달성 못함").length;
  const dates = mine.flatMap(q => [ds(q.start), ds(q.due)]).filter(Boolean).sort();
  const from = [ds(p.start), dates[0]].filter(Boolean).sort()[0] ?? null;
  const to = ds(p.due) ?? (dates.length ? dates[dates.length - 1] : null);
  return { mine, done, total, from, to, pct: total ? Math.round(done / total * 100) : 0 };
};
const pace = (p, s) => {
  if (p.status === "보류") return "보류";
  if (!s.from || !s.to || !s.total) return "—";
  const dur = dv.date(s.to).diff(dv.date(s.from), "days").days, el = t.diff(dv.date(s.from), "days").days;
  if (dur <= 0) return "—";
  const expected = Math.max(0, Math.min(100, Math.round(el / dur * 100)));
  const diff = s.pct - expected;
  const label = diff >= -10 ? "🟢 순항" : diff >= -30 ? "🟡 주의" : "🔴 지연";
  return `${label} (계획 ${expected}% · 실제 ${s.pct}%)`;
};
const row = p => { const s = stats(p); return [
  `${p.emoji ?? EMOJI(`${linkName(p.area)} ${p.file.name}`)} ${p.file.link}` + (p.status && p.status !== "진행 중" ? ` \`${p.status}\`` : ""),
  p.area ?? "",
  s.from || s.to ? `${s.from ? md(s.from) : "?"} ~ ${s.to ? md(s.to) : "?"}` : "—",
  `${s.pct}% (${s.done}/${s.total})`,
  dday(s.to),
  pace(p, s),
  p.next_action ?? "—",
]; };
const rank = p => { const i = ORDER.indexOf(p.status); return i < 0 ? ORDER.length : i; };
const open = projects.filter(p => p.status !== "완료").sort((a, b) => rank(a) - rank(b) || (ds(a.due) ?? "9999").localeCompare(ds(b.due) ?? "9999"));
const doneP = projects.filter(p => p.status === "완료");
dv.paragraph(`**진행 중 ${projects.filter(p => p.status === "진행 중").length}** · 전체 **${projects.length}**`);
const H = ["프로젝트", "분야", "기간", "진행률", "마감까지", "진도", "다음 행동"];
open.length ? dv.table(H, open.map(row)) : dv.paragraph("아직 프로젝트가 없어요. `Ctrl/Cmd+N` → 🗂️ 프로젝트로 시작해보세요.");
if (doneP.length) { dv.header(3, `완료 ${doneP.length}`); dv.table(H, doneP.map(row)); }
```

> 진행률 = (체크리스트 완료 + 할 일 완료) / (체크리스트 전체 + 할 일 중 달성 못함 제외). 기간은 `start`와 할 일 날짜 중 가장 이른 날 ~ `due`(없으면 가장 늦은 할 일 날짜). 진도는 앱과 같은 규칙 — 실제 − 계획이 −10 이상이면 순항, −30 이상이면 주의, 그 외 지연.

## 이번 달 마감
```dataview
TABLE WITHOUT ID file.link AS "프로젝트", status AS "상태", due AS "마감", next_action AS "다음 행동"
FROM "40_프로젝트"
WHERE type = "프로젝트" AND !yk_deleted AND !yk_missing AND status != "보류" AND status != "완료" AND due AND due >= date(today) AND due.year = date(today).year AND due.month = date(today).month
SORT due ASC
```

## 분야별
```dataview
TABLE WITHOUT ID area AS "분야", length(rows) AS "프로젝트", rows.file.link AS "목록"
FROM "40_프로젝트"
WHERE type = "프로젝트" AND !yk_deleted AND !yk_missing
GROUP BY area
SORT length(rows) DESC
```

## 자료 (최근)
```dataview
TABLE WITHOUT ID file.link AS "자료", project AS "프로젝트", kind AS "종류", updated AS "수정"
FROM "40_프로젝트"
WHERE type = "자료" AND !yk_missing
SORT updated DESC
LIMIT 15
```

## 쓰는 법
- **새 프로젝트**: `Ctrl/Cmd+N` → 🗂️ 프로젝트 → 이름 · 분야([[분야]] 중 선택, 기본 **개인**) · 마감 → `40_프로젝트/<이름>/<이름>.md`. 앱에서 만든 프로젝트는 가져오기가 같은 구조로 만든다.
- **체크리스트**: 프로젝트 노트 `## 체크리스트`에 `- [ ]`로. 묶음은 `### 묶음 이름` 소제목. 앱의 묶음 · 체크 항목은 `%% yk:checklist %%` 블록 안에 들어오고, 블록 밖의 줄은 보존된다.
- **할 일 연결**: 할 일 노트의 `project: "[[이름]]"`. ⚡ 빠른 입력에서 `#이름`, `@이름`, `[이름]`, 알려진 프로젝트 이름 단독으로도 붙는다.
- **자료**: `Ctrl/Cmd+N` → 📎 자료 (프로젝트에) → URL/제목 → `40_프로젝트/<이름>/자료/`. URL이 유튜브면 제목 "유튜브 영상", 아니면 "<호스트> 글". 자료는 문헌(파랑)으로 그려진다.
- **진행**: 각 프로젝트 노트 `## 진행`에 같은 계산이 들어 있다.
