# ☀️ 오늘 — 시간축

> 일간 노트는 **시냅스**다. 그날의 하루 계획 · 습관 체크 · 마감 할 일 · 일기 · 새로 생긴 노트가 전부 날짜 하나에 모인다(YouKnow `#/today` 화면과 같은 순서).
> 그래서 그래프에서 날짜 노드를 잡으면 "그날의 내 뇌"가 통째로 딸려 나온다.

## 오늘 · 이번 주
```dataviewjs
const t = dv.date("today");
const today = t.toFormat("yyyy-MM-dd");
const week  = moment().format("GGGG-[W]WW");
const dows  = ["일","월","화","수","목","금","토"];
const ds = v => !v ? null : (v.toFormat ? v.toFormat("yyyy-MM-dd") : String(v).slice(0, 10));
const byDate = {};
for (const p of dv.pages('"10_오늘"').where(p => p.type === "오늘" && p.date)) byDate[ds(p.date)] = p;
const sun = t.minus({ days: t.weekday % 7 });  // 앱과 같은 일요일 시작 주
dv.paragraph(`☀️ [[${today}]] (${dows[t.weekday % 7]}) · 🗓️ 주간 리뷰 [[${week}]] · 요일 일과 [[${dows[t.weekday % 7]}요일]]`);
const cells = [];
for (let i = 0; i < 7; i++) {
  const d = sun.plus({ days: i }); const key = d.toFormat("yyyy-MM-dd"); const p = byDate[key];
  const mark = key === today ? "**" : "";
  const info = p ? ` ${p.plans_done ?? 0}/${p.plans ?? 0}` : (d > t ? "" : " ·");
  cells.push(`${mark}${dows[i]} [[${key}\|${d.toFormat("M/d")}]]${info}${mark}`);
}
dv.paragraph("이번 주(일~토): " + cells.join(" · ") + "  _(숫자 = 하루 계획 완료/전체)_");
```

## 최근 14일
```dataviewjs
const ds = v => !v ? null : (v.toFormat ? v.toFormat("yyyy-MM-dd") : String(v).slice(0, 10));
const dows = ["일","월","화","수","목","금","토"];
const pages = dv.pages('"10_오늘"').where(p => p.type === "오늘" && p.date).sort(p => ds(p.date), "desc").slice(0, 14);
const bar = (done, total) => total ? "█".repeat(Math.round(done / total * 5)).padEnd(5, "░") + ` ${Math.round(done / total * 100)}%` : "—";
dv.table(["날짜", "요일", "하루 계획", "완료율", "습관 체크", "연결된 뉴런"], pages.map(p => {
  const d = p.date.toFormat ? p.date : dv.date(ds(p.date));
  const plans = p.plans ?? 0, done = p.plans_done ?? 0;
  const neurons = p.file.inlinks.filter(l => !String(l.path).startsWith("10_오늘/")).length;
  return [p.file.link, dows[d.weekday % 7], `${done}/${plans}`, bar(done, plans), p.habits_checked ?? 0, neurons];
}));
```

## 주간 리뷰
```dataview
TABLE WITHOUT ID file.link AS "주", start AS "시작", end AS "끝"
FROM "10_오늘/Weekly"
WHERE type = "주간"
SORT file.name DESC
LIMIT 8
```

## 구조
- `10_오늘/YYYY/MM/YYYY-MM-DD.md` — 일간 노트. Calendar 플러그인에서 날짜를 클릭하거나 `오늘의 노트 열기`. 가져오기(`import_youknow.py`)는 가장 오래된 앱 데이터 날짜부터 오늘까지 **매일** 스켈레톤을 만들어 전날 · 다음날 · 주차 · 요일 사슬이 끊기지 않게 한다.
- `10_오늘/Weekly/GGGG-Www.md` — 주간 리뷰. Calendar에서 주차 숫자 클릭. 집계는 앱처럼 **일요일 시작** 주로 한다.
- 일간 노트의 섹션 순서는 YouKnow 오늘 화면과 같다: `🗓️ 오늘 일정`(하루 계획 · 캘린더 · 일과) → `✅ 오늘 할 일`(지난 마감 · 오늘 마감 · 달성 못함) → `🔁 습관` → `📔 오늘 일기` → `📝 메모` → `🧠 오늘 생긴 뉴런`.
- **하루 계획과 습관 체크는 체크박스가 아니라 이모지 불릿**(✅ 완료 · ❌ 달성 못함 · ⬜ 미완)이다. Tasks 플러그인이 할 일로 오인하지 않게 하기 위해서다. `%% yk:… %%` 마커 사이는 가져오기가 다시 쓰는 영역이고, 마커 밖의 줄(옵시디언에서 직접 쓴 계획)은 보존된다.
- 계획 제목이 [[🔁 습관]] 또는 [[🗓️ 일정|요일 일과]] 노트 제목과 같으면 `[[링크]]`가 되어 일간 → 습관 선이 그어진다.
