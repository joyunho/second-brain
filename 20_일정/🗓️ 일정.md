# 🗓️ 일정 — 달력

> YouKnow `#/schedule` 화면. 하루 계획(일간 노트의 `### 하루 계획`), 할 일 마감, Google Calendar 일정, 요일별 일과표가 한 달력 위에 겹친다.
> 집계는 앱과 같이 **일요일 시작 주(일~토)**로 한다.

## 이번 주
```dataviewjs
const t = dv.date("today");
const ds = v => !v ? null : (v.toFormat ? v.toFormat("yyyy-MM-dd") : String(v).slice(0, 10));
const dows = ["일","월","화","수","목","금","토"];
const sun = t.minus({ days: t.weekday % 7 }), sat = sun.plus({ days: 6 });
const byDate = {};
for (const p of dv.pages('"10_오늘"').where(p => p.type === "오늘" && p.date)) byDate[ds(p.date)] = p;
const tasks = dv.pages('"30_할일/목록"').where(p => p.type === "할일" && p.due);
const inWeek = d => d >= sun.toFormat("yyyy-MM-dd") && d <= sat.toFormat("yyyy-MM-dd");
const dueWeek = tasks.where(p => inWeek(ds(p.due)));
let plans = 0, done = 0; const rows = [];
for (let i = 0; i < 7; i++) {
  const d = sun.plus({ days: i }); const key = d.toFormat("yyyy-MM-dd"); const p = byDate[key];
  const n = p?.plans ?? 0, k = p?.plans_done ?? 0; plans += n; done += k;
  const due = dueWeek.where(q => ds(q.due) === key);
  rows.push([
    (key === ds(t) ? "**오늘** " : "") + `[[${key}|${d.toFormat("M/d")} (${dows[i]})]]`,
    p ? `${k}/${n}` : "—",
    p && n ? `${Math.round(k / n * 100)}%` : "—",
    due.length ? due.map(q => q.file.link).array().join(", ") : "",
    `[[${dows[i]}요일]]`,
  ]);
}
const pct = plans ? Math.round(done / plans * 100) : 0;
dv.paragraph(`**${sun.toFormat("M/d")} ~ ${sat.toFormat("M/d")}** · 이번 주 마감 **${dueWeek.length}** · 계획 **${plans}** · 완료 **${pct}%** (${done}/${plans})`);
dv.table(["날짜", "계획", "완료율", "마감 할 일", "일과"], rows);
```

## 이번 달
```dataviewjs
const t = dv.date("today");
const ds = v => !v ? null : (v.toFormat ? v.toFormat("yyyy-MM-dd") : String(v).slice(0, 10));
const ym = t.toFormat("yyyy-MM");
const days = dv.pages('"10_오늘"').where(p => p.type === "오늘" && p.date && ds(p.date).startsWith(ym));
const planned = days.where(p => (p.plans ?? 0) > 0).length;
const due = dv.pages('"30_할일/목록"').where(p => p.type === "할일" && p.due && ds(p.due).startsWith(ym)).length;
const diaries = dv.pages('"50_일기"').where(p => p.type === "일기" && p.date && ds(p.date).startsWith(ym)).length;
dv.paragraph(`**${t.month}월** · 마감 **${due}** · 계획 있는 날 **${planned}** · 일기 있는 날 **${diaries}**`);
```

### 앞으로 7일 마감 (할 일 노트)
```dataview
TABLE WITHOUT ID file.link AS "할 일", due AS "마감", priority_label AS "우선순위", project AS "프로젝트"
FROM "30_할일/목록"
WHERE type = "할일" AND due AND due >= date(today) AND due <= date(today) + dur(6 days) AND status != "완료" AND status != "달성 못함"
SORT due ASC, priority DESC
```

## 🔁 요일별 일과표
- [[일요일]] · [[월요일]] · [[화요일]] · [[수요일]] · [[목요일]] · [[금요일]] · [[토요일]]
- 요일 노트(`20_일정/일과/<요일>요일.md`)의 `## 일과표`는 YouKnow `routine_blocks`(앱 "일과" 보기)에서 가져온다. 일과 제목이 습관 노트와 같으면 `[[링크]]`.
- 하루 계획이 **0개**인 날의 일간 노트에는 그 요일의 일과표가 `![[금요일#일과표]]`로 임베드된다(앱의 "일과 N" 접기와 같은 규칙). 계획이 생기면 사라진다.
- 앱의 "{요일}요일 일과 가져오기"처럼 일과를 그날 계획으로 복사하려면 앱에서 하거나, 옵시디언에서 ⚡ 빠른 입력에 `매주 월수금 저녁 7시 헬스`처럼 적는다 → 요일 노트에 행이 추가된다.

```dataview
TABLE WITHOUT ID file.link AS "요일", weekday AS "번호", length(file.inlinks) AS "가리키는 일간 노트"
FROM "20_일정/일과"
WHERE type = "일과"
SORT weekday ASC
```

## 📅 Google Calendar
- **ICS 플러그인**에 Google Calendar의 비공개 iCal 주소를 등록하면 일간 노트를 만들 때 `### 캘린더`에 그날 일정이 자동으로 들어온다(tpl-daily). 캘린더 자체를 볼트에 저장하지는 않는다 — 일간 노트가 그날의 스냅샷이다.
- YouKnow 앱의 Google 계정 연동 일정은 서버 세션 전용이라 가져오기 대상이 아니다. 같은 Google 캘린더를 ICS로 직접 읽는다.
- 선택: YouKnow의 `/api/calendar.ics?type=tasks`를 ICS에 추가하면 스크립트 없이 📌 마감이 뜨지만, `import_youknow.py`와 같이 쓰면 중복이므로 둘 중 하나만.
- 설정 절차는 [[🔌 연동]] 참고.
