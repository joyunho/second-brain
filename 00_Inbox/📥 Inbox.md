# 📥 Inbox — 입구

> 모든 입력의 시작점. 여기 있는 노트는 아직 **자리를 못 찾은 것**. 비울수록 뇌가 맑아진다.
> `Ctrl/Cmd+N`으로 만든 노트는 기본적으로 이 폴더에 생기고, 라우터 메뉴에서 유형을 고르면 처음부터 제자리로 간다.

## 처리 대기
```dataview
TABLE WITHOUT ID file.link AS "노트", file.tags AS "태그", file.cday AS "생성", round((number(dateformat(date(today), "X")) - number(dateformat(file.cday, "X"))) / 86400) AS "경과(일)"
FROM "00_Inbox"
WHERE type != "허브"
SORT file.cday ASC
```

## 자리 찾아주는 3가지 방법
1. **태그 하나** — 본문 아무 데나 `#책` `#글` `#일기` `#영구` `#프로젝트` `#사람` `#분야` `#할일` `#습관` `#굿노트` 중 하나를 붙이면 Auto Note Mover가 폴더로 옮긴다. 옮긴 뒤 `Templater: Insert template`로 템플릿을 입히면 끝. (프로젝트 **자료**는 태그로 옮기지 않는다 — 라우터의 "📎 자료 (프로젝트에)"를 쓴다.)
2. **드래그** — 파일 탐색기에서 폴더로 끌어다 놓는다. 폴더 템플릿이 자동으로 적용된다.
3. **삭제** — 다시 볼 일 없으면 과감히.

## ⚡ 빠른 입력으로 쪼개기
- 메모 한 덩어리가 사실 할 일 · 계획 · 습관의 묶음이면, 본문을 복사해 `Ctrl/Cmd+N` → **⚡ 빠른 입력**에 붙여 넣는다. YouKnow와 같은 규칙으로 한 줄씩 나눠 [[✅ 할 일]] · [[☀️ 오늘]] · [[🔁 습관]] · [[🗓️ 일정]] · [[🗂️ 프로젝트]]로 보낸다.
- 파일명이 `⚡`로 시작하는 노트(iOS 단축어 "뇌에 추가")는 메뉴 없이 바로 쪼개진다.

> [!tip] 애초에 Inbox에 안 쌓이게 하려면
> 새 노트를 만들 때 뜨는 "이 노트는 무엇인가요?" 메뉴에서 유형을 고르세요. 폴더 · 속성 · 링크는 템플릿이 만듭니다.
