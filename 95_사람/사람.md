# 👤 사람 — 사람

> 일기나 일간 노트에서 사람 이름을 `[[ ]]`로 감싸면, 그 사람 노트가 자동으로 그 날과 연결된다. 일기의 `태그`(예: `[[친구]]`)와는 다르다 — 태그는 분류, 사람 노트는 개인이다.

## 사람들
```dataview
TABLE WITHOUT ID file.link AS "이름", role AS "관계", last_contact AS "마지막 연락", length(file.inlinks) AS "언급", area AS "분야"
FROM "95_사람"
WHERE type = "사람"
SORT last_contact DESC
```

## 오래 연락 안 한 사람 (60일+)
```dataview
LIST last_contact
FROM "95_사람"
WHERE type = "사람" AND last_contact AND last_contact < date(today) - dur(60 days)
SORT last_contact ASC
```

## 최근에 언급된 사람
```dataviewjs
const people = dv.pages('"95_사람"').where(p => p.type === "사람").array();
const rows = people.map(p => {
  const mentions = p.file.inlinks.array().map(l => dv.page(l.path)).filter(q => q && (q.type === "일기" || q.type === "오늘")).sort((a, b) => String(b.file.name).localeCompare(String(a.file.name)));
  return [p.file.link, mentions.length, mentions.slice(0, 3).map(q => q.file.link).join(", ")];
}).filter(r => r[1] > 0).sort((a, b) => b[1] - a[1]).slice(0, 15);
rows.length ? dv.table(["사람", "일기 · 일간 언급", "최근"], rows) : dv.paragraph("아직 일기나 일간 노트에서 언급된 사람이 없어요.");
```

## 쓰는 법
- `Ctrl/Cmd+N` → 👤 사람, 또는 Inbox 노트에 `#사람`.
- `role`(관계), `last_contact`(마지막 연락일), `area: "[[관계]]"` 등을 채운다. 연락한 날에는 일간 노트에서 `[[이름]]`으로 부르고 `last_contact`를 갱신한다.
