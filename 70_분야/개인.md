# 📁 개인

> [!abstract] 이 분야에서 지키고 싶은 기준
> YouKnow 앱의 기본 분야. 분야를 따로 적지 않은 프로젝트가 여기로 온다.

## 진행 중인 프로젝트
```dataview
TABLE WITHOUT ID file.link AS "프로젝트", status AS "상태", due AS "마감", next_action AS "다음 행동"
FROM "40_프로젝트"
WHERE type = "프로젝트" AND contains(string(area), "개인") AND status != "완료"
SORT status ASC, due ASC
```

## 이 분야의 뉴런들
```dataview
TABLE WITHOUT ID file.link AS "노트", type AS "유형", file.cday AS "날짜"
FROM -"_System" AND -"70_분야"
WHERE contains(string(area), "개인")
SORT file.cday DESC
LIMIT 30
```
