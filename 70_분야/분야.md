# 🧭 분야 — 삶의 영역

> 프로젝트는 끝나지만 분야는 끝나지 않는다. YouKnow 프로젝트의 `분야` 속성(기본값 **개인**)이 그대로 `70_분야/<이름>.md`가 되고, 책 · 글 · 영구 노트 · 사람도 `area: "[[건강]]"`으로 여기 매달린다.
> 그래프에서는 분야 노트가 **빨간 구조 노드**(`#hub`)가 되어 뇌의 큰 가지를 만든다. 이모지는 앱 규칙(건강·운동 💪, 유튜브·영상 🎬, 게임 🎮, 스타일 💇, 공부·영어·독서 📚, 돈·주식 💰, 생활·집 🏠, 그 외 📁)을 따른다.

## 분야 목록
```dataviewjs
const linkName = v => !v ? "" : (v.path ? String(v.path) : String(v).replace(/^\[\[|\]\]$/g, "").split("|")[0]).split("/").pop().replace(/\.md$/, "");
const areas = dv.pages('"70_분야"').where(p => p.type === "분야").array();
const projects = dv.pages('"40_프로젝트"').where(p => p.type === "프로젝트" && !p.yk_deleted && !p.yk_missing).array();
const others = dv.pages('-"_System" AND -"70_분야" AND -"40_프로젝트"').where(p => p.area).array();
const rows = areas.map(a => {
  const name = a.file.name;
  const mine = projects.filter(p => linkName(p.area) === name || String(p.area ?? "") === name);
  const active = mine.filter(p => p.status !== "완료");
  const neurons = others.filter(p => (Array.isArray(p.area) ? p.area : [p.area]).some(v => linkName(v) === name));
  return [`${a.emoji ?? "📁"} ${a.file.link}`, a.file.inlinks.length, `${active.length} / ${mine.length}`, neurons.length, active.map(p => p.file.link).join(", ")];
}).sort((x, y) => y[1] - x[1]);
rows.length ? dv.table(["분야", "연결된 뉴런", "진행 중 / 전체 프로젝트", "문헌 · 영구 · 사람", "진행 중인 프로젝트"], rows) : dv.paragraph("아직 분야가 없어요.");
```

## 분야 없는 프로젝트
```dataview
LIST
FROM "40_프로젝트"
WHERE type = "프로젝트" AND !area AND !yk_deleted AND !yk_missing
```

## 쓰는 법
- **새 분야**: `Ctrl/Cmd+N` → 🧭 분야. 앱에서 프로젝트에 새 분야 이름을 적으면 가져오기가 `70_분야/<이름>.md`를 자동으로 만든다(`yk_area: true`).
- 노트에 `area: "[[건강]]"`을 적으면 이 분야에 매달린다. 프로젝트 · 책 · 글 · 굿노트 · 영구 노트 · 사람이 대상이고, 할 일은 프로젝트를 거쳐 간접 연결된다.
- 시작 분야: [[개인]](앱 기본값) · [[건강]] · [[커리어]] · [[돈]] · [[관계]] · [[배움]]. 앱에서 "공부"처럼 다른 이름을 쓰면 별도 노트가 생기니, 합치고 싶으면 둘 중 하나로 이름을 통일한다.
