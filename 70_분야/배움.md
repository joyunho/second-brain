# 🧭 배움

> [!abstract] 이 영역에서 지키고 싶은 기준
> 

## 진행 중인 프로젝트
```dataview
LIST FROM "30_Tasks/Projects" WHERE contains(string(area), "배움") AND status != "done"
```

## 이 영역의 뉴런들
```dataview
TABLE WITHOUT ID file.link AS "노트", type AS "유형", file.cday AS "날짜"
FROM -"_System" AND -"60_Areas"
WHERE contains(string(area), "배움")
SORT file.cday DESC
LIMIT 30
```
