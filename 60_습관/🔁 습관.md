# 🔁 습관 — 반복

> YouKnow `#/habits` 화면. 습관 하나 = `60_습관/<이름>.md`. 체크 기록은 습관 노트가 아니라 **그날 일간 노트의 `## 🔁 습관` 블록**(`- ✅ [[헬스]]` / `- ⬜ [[영어]]`)에 있다. 그래서 일간 노트 수백 개가 습관 노트를 가리키고, 습관 노트는 빨간 구조 노드가 된다.
> 집계는 앱과 같다 — 연속일은 오늘(미체크면 어제)부터 거꾸로, 이번 주는 일요일 시작 · 오늘까지의 날만.

```dataviewjs
const t = dv.date("today"), today = t.toFormat("yyyy-MM-dd");
const ds = v => !v ? null : (v.toFormat ? v.toFormat("yyyy-MM-dd") : String(v).slice(0, 10));
const habits = dv.pages('"60_습관"').where(p => p.type === "습관").sort(p => p.sort_order ?? 0).array();
if (!habits.length) dv.paragraph("아직 습관이 없어요. `Ctrl/Cmd+N` → 🔁 습관으로 첫 습관을 추가해보세요.");
// 최근 70일(앱의 로드 창)의 일간 노트에서 ✅ 줄을 읽는다
const since = t.minus({ days: 70 }).toFormat("yyyy-MM-dd");
const days = dv.pages('"10_오늘"').where(p => p.type === "오늘" && p.date && ds(p.date) >= since && ds(p.date) <= today).array();
const checked = new Set(); const seen = new Set();
for (const p of days) {
  const f = app.vault.getAbstractFileByPath(p.file.path); if (!f) continue;
  const text = await app.vault.cachedRead(f);
  let block = text;
  const m = text.match(/%% yk:habits:start %%([\s\S]*?)%% yk:habits:end %%/);
  if (m) block = m[1]; else { const s = text.match(/\n## 🔁 습관\n([\s\S]*?)(?=\n## |$)/); if (s) block = s[1]; else continue; }
  const d = ds(p.date);
  for (const line of block.split("\n")) {
    const mm = line.match(/^- (✅|⬜|❌) \[\[([^\]|]+)(?:\|[^\]]*)?\]\]/); if (!mm) continue;
    seen.add(`${mm[2]}:${d}`); if (mm[1] === "✅") checked.add(`${mm[2]}:${d}`);
  }
}
const has = (name, d) => checked.has(`${name}:${d}`);
const streak = name => { let cur = has(name, today) ? t : t.minus({ days: 1 }), n = 0; while (has(name, cur.toFormat("yyyy-MM-dd"))) { n++; cur = cur.minus({ days: 1 }); } return n; };
const sun = t.minus({ days: t.weekday % 7 });
const weekPct = (name, start) => { let c = 0, n = 0; for (let i = 0; i < 7; i++) { const d = start.plus({ days: i }); if (d > t) break; n++; if (has(name, d.toFormat("yyyy-MM-dd"))) c++; } return n ? Math.round(c / n * 100) : 0; };
const todayPage = days.find(p => ds(p.date) === today);
const todayChecked = todayPage?.habits_checked ?? habits.filter(h => has(h.file.name, today)).length;
// 헤더: 오늘 n/m · 이번 주 % · 최장 연속
let wc = 0, wn = 0; for (let i = 0; i < 7; i++) { const d = sun.plus({ days: i }); if (d > t) break; for (const h of habits) { wn++; if (has(h.file.name, d.toFormat("yyyy-MM-dd"))) wc++; } }
const streaks = habits.map(h => streak(h.file.name));
const best = streaks.length ? Math.max(...streaks) : 0;
dv.paragraph(`**오늘 ${todayChecked}/${habits.length}** · 이번 주 **${wn ? Math.round(wc / wn * 100) : 0}%**` + (best ? ` · 🔥 **${best}일**` : ""));
// 습관별 표
const spark = name => { let s = ""; for (let w = 7; w >= 0; w--) { const start = sun.minus({ weeks: w }); const pct = weekPct(name, start); s += pct >= 90 ? "█" : pct >= 70 ? "▆" : pct >= 50 ? "▄" : pct >= 25 ? "▂" : "▁"; } return s; };
const ym = t.toFormat("yyyy-MM");
dv.table(["습관", "색", "오늘", "연속", "이번 주", "최근 8주", "이번 달"], habits.map((h, i) => {
  const name = h.file.name;
  let monthCount = 0; for (let d = 1; d <= t.day; d++) if (has(name, `${ym}-${String(d).padStart(2, "0")}`)) monthCount++;
  return [h.file.link, h.color_name ?? h.color ?? "", has(name, today) ? "✅" : "⬜", `${streaks[i]}일 연속`, `${weekPct(name, sun)}%`, spark(name), `${monthCount}회`];
}));
// 주별 달성률 · 최근 8주
dv.header(3, "주별 달성률 · 최근 8주");
const wrows = [];
for (let w = 7; w >= 0; w--) {
  const start = sun.minus({ weeks: w }); let c = 0, n = 0;
  for (let i = 0; i < 7; i++) { const d = start.plus({ days: i }); if (d > t) break; for (const h of habits) { n++; if (has(h.file.name, d.toFormat("yyyy-MM-dd"))) c++; } }
  const pct = n ? Math.round(c / n * 100) : 0;
  wrows.push([(w === 0 ? "**이번 주** " : "") + start.toFormat("M/d") + " ~", "█".repeat(Math.round(pct / 10)).padEnd(10, "░") + ` ${pct}%`, `${c}/${n}`]);
}
dv.table(["주", "달성률", "체크/가능"], wrows);
// 이번 달
let total = 0; const per = {};
for (let d = 1; d <= t.day; d++) for (const h of habits) if (has(h.file.name, `${ym}-${String(d).padStart(2, "0")}`)) { total++; per[h.file.name] = (per[h.file.name] ?? 0) + 1; }
const top = Object.entries(per).sort((a, b) => b[1] - a[1])[0];
const avg = habits.length ? Math.round(total / (t.day * habits.length) * 100) : 0;
dv.paragraph(`**이번 달** · 총 체크 **${total}** · 하루 평균 **${avg}%** · 최고 습관 **${top ? `${top[0]} · ${top[1]}회` : "—"}**`);
if (seen.size === 0 && habits.length) dv.paragraph("> 아직 일간 노트에 습관 블록이 없어요. `import_youknow.py`를 돌리거나 오늘 노트의 `## 🔁 습관` 아래에 `- ✅ [[습관 이름]]`을 적으면 집계돼요.");
```

## 습관 목록
```dataview
TABLE WITHOUT ID file.link AS "습관", color_name AS "색", sort_order AS "순서", created AS "시작", length(file.inlinks) AS "가리키는 날"
FROM "60_습관"
WHERE type = "습관"
SORT sort_order ASC, file.name ASC
```

## 쓰는 법
- **새 습관**: `Ctrl/Cmd+N` → 🔁 습관, 또는 ⚡ 빠른 입력에 `매일 영어 단어 20개` / `3일마다 청소` / `1일 1커밋` / 요일 없는 `매주 …`. 앱에서 만든 습관은 가져오기가 `60_습관/<이름>.md`로 만든다.
- **체크**: 폰에서는 YouKnow 앱의 오늘 화면 체크 버튼 → 밤에 일간 노트 블록에 반영(앱 승 — 볼트에만 ✅인 줄은 ⬜로 바뀌고 `yk_dirty`로 기록). 옵시디언에서는 오늘 일간 노트 `## 🔁 습관`의 `- ⬜ [[이름]]`을 `- ✅`로 고친다(체크박스가 아니라 이모지 — Tasks 플러그인이 할 일로 긁어가지 않게).
- 하루 계획 제목이 습관 이름과 같으면(`09:00–10:00 [[헬스]]`) 계획 줄도 습관 노트로 선이 그어진다.
- 각 습관 노트 `## 기록`에 연속일 · 이번 주 % · 최근 8주 막대가 따로 있다.
