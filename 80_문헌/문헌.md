# 📚 문헌 — 인풋

> 바깥에서 들어온 것. 책(`80_문헌/책`), 글 · 영상 · 강의(`80_문헌/글`), GoodNotes 손글씨(`80_문헌/굿노트`), 그리고 프로젝트의 자료(`40_프로젝트/<이름>/자료`). 그래프에서 전부 **파랑**.
> 여기서 소화된 것은 [[영구 노트]]로 넘어가 "내 것"이 된다 — 문헌 노트의 `## 이 책에서 나온 영구 노트`가 그 통로다.

## 📖 읽는 중
```dataview
TABLE WITHOUT ID file.link AS "책", author AS "저자", started AS "시작", area AS "분야"
FROM "80_문헌/책"
WHERE type = "책" AND (status = "reading" OR status = "읽는 중")
SORT started DESC
```

## ✅ 완독
```dataview
TABLE WITHOUT ID file.link AS "책", author AS "저자", rating AS "⭐", finished AS "완독", area AS "분야"
FROM "80_문헌/책"
WHERE type = "책" AND (status = "done" OR status = "완독")
SORT finished DESC
```

## 🛒 읽고 싶은
```dataview
LIST author
FROM "80_문헌/책"
WHERE type = "책" AND (status = "want" OR status = "읽고 싶은")
SORT file.ctime DESC
```

## 📰 글 · 영상 · 강의
```dataview
TABLE WITHOUT ID file.link AS "제목", kind AS "종류", author AS "출처", file.cday AS "날짜", area AS "분야"
FROM "80_문헌/글"
WHERE type = "글"
SORT file.cday DESC
LIMIT 20
```

## 📈 올해
```dataviewjs
const year = dv.date("today").year;
const books = dv.pages('"80_문헌/책"').where(p => p.type === "책");
const done = books.where(p => (p.status === "done" || p.status === "완독") && p.finished && p.finished.year === year);
const rated = done.where(p => p.rating);
const avg = rated.length ? (rated.array().reduce((s, p) => s + Number(p.rating), 0) / rated.length).toFixed(1) : "–";
const articles = dv.pages('"80_문헌/글"').where(p => p.type === "글" && p.file.cday.year === year).length;
const gn = dv.pages('"80_문헌/굿노트"').where(p => p.type === "굿노트" && p.file.cday.year === year).length;
const ideas = dv.pages('"90_영구"').where(p => p.type === "영구" && p.source && p.file.cday.year === year).length;
dv.paragraph(`${year}년 완독 **${done.length}권** · 평균 별점 **${avg}** · 글 **${articles}** · 굿노트 **${gn}** · 문헌에서 나온 영구 노트 **${ideas}**`);
```

## 쓰는 법
- `Ctrl/Cmd+N` → 📖 독후감 / 책 · 📰 글 / 영상 / 강의. 또는 Inbox 노트에 `#책` `#글` `#굿노트`를 붙이면 Auto Note Mover가 옮긴다.
- 책 `status`: want → reading → done · `rating` 1~5. 글 `kind`: article · video · podcast · lecture · paper.
- 모든 문헌 노트에 `area: "[[분야]]"`를 적어 [[분야]]에 매단다.
- GoodNotes는 `import_goodnotes.py`가 `80_문헌/굿노트/<노트북>.md`(PDF 임베드)로 만든다 → [[연동]].
