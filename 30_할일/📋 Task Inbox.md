# 📋 Task Inbox

> 급하게 떠오른 할 일을 **노트 없이 한 줄**로 던지는 곳. `📅 YYYY-MM-DD`를 붙이면 그날 일간 노트 `### 오늘 마감`에 자동으로 뜬다.
> 주간 리뷰 때 **⚡ 빠른 입력**(`Ctrl/Cmd+N` → ⚡)에 줄을 붙여 넣어 `30_할일/목록` 노트로 승격하거나, 날짜를 주거나, 지운다. 승격한 줄은 여기서 삭제.
