# ✅ 할 일 — 실행

> YouKnow `#/tasks` 화면. 할 일 하나 = `30_할일/목록/<제목>.md` 노트 하나(앱의 세부 메모 화면과 같다). 노트 없이 한 줄로 던지는 체크박스는 [[Task Inbox]]와 일간 노트에.
> 상태는 **진행 전 · 진행 중 · 완료 · 달성 못함**, 우선순위는 **긴급(5) · 중요(4) · 보통(3) · 낮음(2) · 언젠가(1)** — 평문 값이라 그래프에 별을 만들지 않는다.

```dataviewjs
const t = dv.date("today"), today = t.toFormat("yyyy-MM-dd");
const ds = v => !v ? null : (v.toFormat ? v.toFormat("yyyy-MM-dd") : String(v).slice(0, 10));
const all = dv.pages('"30_할일/목록"').where(p => p.type === "할일" && !p.yk_deleted && !p.yk_missing);   // 앱 휴지통·사라진 행은 앱처럼 제외
const active = all.where(p => p.status !== "완료" && p.status !== "달성 못함");
const dueToday = active.where(p => ds(p.due) === today).length;
const overdue  = active.where(p => p.due && ds(p.due) < today).length;
const done = all.where(p => p.status === "완료").length;
const failed = all.where(p => p.status === "달성 못함").length;
const denom = all.length - failed;
const ring = denom ? Math.round(done / denom * 100) : 0;
dv.paragraph(`**남은 ${active.length}** · 오늘 마감 **${dueToday}** · 마감 지남 **${overdue}**`);
dv.paragraph(`상태별: 진행 전 ${all.where(p => p.status === "진행 전").length} · 진행 중 ${all.where(p => p.status === "진행 중").length} · 완료 ${done} · 달성 못함 ${failed} — **${ring}% 완료** (${done}/${denom}) _달성 못함 ${failed}개는 빼고 계산했어요_`);
```

## 목록
```dataviewjs
const t = dv.date("today"), today = t.toFormat("yyyy-MM-dd");
const ds = v => !v ? null : (v.toFormat ? v.toFormat("yyyy-MM-dd") : String(v).slice(0, 10));
const LABEL = { 5: "긴급", 4: "중요", 3: "보통", 2: "낮음", 1: "언젠가" };
const all = dv.pages('"30_할일/목록"').where(p => p.type === "할일" && !p.yk_deleted && !p.yk_missing).array();
const isActive = p => p.status !== "완료" && p.status !== "달성 못함";
// 앱과 같은 정렬: 활성 우선 → 우선순위 내림차순 → 마감 오름차순(없으면 맨 뒤)
all.sort((a, b) => (isActive(b) - isActive(a)) || ((b.priority ?? 3) - (a.priority ?? 3)) || ((ds(a.due) ?? "9999-99-99").localeCompare(ds(b.due) ?? "9999-99-99")));
const dday = d => { if (!d) return "—"; const n = Math.round(dv.date(d).diff(t, "days").days); return n === 0 ? "오늘" : n > 0 ? `D-${n}` : `D+${-n}`; };
const row = p => [p.file.link, p.status ?? "—", p.project ?? "", ds(p.due) ? `[[${ds(p.due)}]]` : "—", dday(ds(p.due))];
const active = all.filter(isActive);
if (!active.length) dv.paragraph("남은 할 일이 없어요. ⚡ 빠른 입력이나 [[Task Inbox]]에서 바로 추가해보세요.");
for (const pr of [5, 4, 3, 2, 1]) {
  const group = active.filter(p => (p.priority ?? 3) === pr);
  if (!group.length) continue;
  dv.header(3, `${LABEL[pr]} ${group.length}`);
  dv.table(["할 일", "상태", "프로젝트", "마감", "남은 날"], group.map(row));
}
// 접힌 섹션(앱의 "완료 N" · "달성 못함 N")
const sun = t.minus({ days: t.weekday % 7 }).toFormat("yyyy-MM-dd"), sat = t.plus({ days: 6 - t.weekday % 7 }).toFormat("yyyy-MM-dd");
const done = all.filter(p => p.status === "완료");
const doneWeek = done.filter(p => ds(p.due) && ds(p.due) >= sun && ds(p.due) <= sat).length;
const failed = all.filter(p => p.status === "달성 못함");
dv.header(3, `완료 ${done.length} · 이번 주 ${doneWeek}`);
done.length ? dv.table(["할 일", "상태", "프로젝트", "마감", "남은 날"], done.slice(0, 20).map(row)) : dv.paragraph("완료한 할 일이 없어요.");
dv.header(3, `달성 못함 ${failed.length}`);
failed.length ? dv.table(["할 일", "상태", "프로젝트", "마감", "남은 날"], failed.slice(0, 20).map(row)) : dv.paragraph("달성 못함으로 접은 할 일이 없어요.");
```


## 📋 체크박스 할 일 (Tasks 플러그인)
> 노트 없는 한 줄 할 일. `30_할일/목록`의 노트 안에도 `- [ ] 제목 … 🆔 yk-xxxxxxxx` 줄이 하나씩 있지만, 위 Dataview 표와 겹치므로 여기서는 뺀다.

### 🔥 오늘 · 밀린 것
```tasks
not done
due before tomorrow
path does not include 30_할일/목록
sort by due
```

### 📆 이번 주 (앞으로 7일)
```tasks
not done
due after today
due before in 7 days
path does not include 30_할일/목록
sort by due
```

### 🗓️ 날짜 없는 것 (Task Inbox 정리 대상)
```tasks
not done
no due date
path includes 30_할일/📋 Task Inbox
limit 20
```

### ✅ 이번 주에 끝낸 것
```tasks
done this week
sort by done
limit 30
```
> [!note] `✅ 완료일`은 앱에서 끝낸 할 일에 한해 근사치
> YouKnow에는 완료 시각 컬럼이 없어서, **앱에서** 끝낸 할 일의 완료 줄에는 **마감일을 완료일로** 붙인다(`✅ <due>`; 마감이 없으면 생략). 옵시디언에서 Tasks로 체크해 `✅ 날짜`가 붙은 할 일은 그 실제 날짜가 그대로 남는다(frontmatter `done`). 위 Tasks 블록의 "이번 주"는 Tasks 정의대로 **월~일(ISO 주)**이고, 아래 "이번 주 N" 카운트는 앱처럼 일~토다.

## 쓰는 법
- **⚡ 빠른 입력** (`Ctrl/Cmd+N` → ⚡): YouKnow 문법 그대로. `9/10까지 영상 편집!!` → 마감 9/10 · 중요, `언젠가 책 정리 #집` → 언젠가 · 프로젝트 "집", `내일 오후 3시 치과` → 하루 계획, `매일 영어 단어 20개` → 습관, `매주 월수금 저녁 7시 헬스` → 일과. 여러 줄을 한 번에 붙여 넣어도 된다.
- **✅ 할 일 (한 개)** (`Ctrl/Cmd+N` → ✅): 제목 · 마감(자연어) · 우선순위 · 프로젝트를 물어보고 `30_할일/목록/<제목>.md`를 만든다. `start`는 오늘, `daily: [[오늘]]` · `마감: [[마감일]]` · `project: [[프로젝트]]` 선이 그어진다.
- **급하게 한 줄**: [[Task Inbox]]에 `- [ ] 할 일 📅 2026-10-17`. 그날 일간 노트 `### 오늘 마감`에 뜬다. 주간 리뷰에서 ⚡로 승격하거나 그대로 둔다.
- **폰**: YouKnow 앱에 적는다 → 밤에 가져오기. 옵시디언에서 만든 할 일을 앱에도 보내려면 `tpl-inbox.md`의 `PUSH_TO_YOUKNOW`를 켠다(→ [[연동]]). 볼트에서 먼저 만든 할 일은 `yk_pending: true`로 표시되고, 야간 가져오기가 앱 행과 맞춰 `yk_id`를 채운다.
- **상태 바꾸기**: 노트의 `status` 속성 또는 체크박스(`[ ]` 진행 전 · `[/]` 진행 중 · `[x]` 완료 · `[-]` 달성 못함). 앱보다 "더 진행"된 값은 가져오기가 지키고 `yk_dirty`로 표시해 앱에 수동 반영을 안내한다.
