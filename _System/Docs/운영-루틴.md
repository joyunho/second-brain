## 🧯 문제가 생겼을 때

### 가져오기가 실패했을 때
1. `98_연동/YouKnow.md` 상단 `⚠️` 줄과 테이블별 로그(생성/갱신/건너뜀/실패) 읽기.
2. `python3 -I _System/Scripts/import_youknow.py --supabase --dry-run`을 손으로 돌려 메시지 확인.
   - 401/403 → `.env`의 `YK_SUPABASE_ANON_KEY`/`YK_OWNER_ID` 확인. RLS가 막는 거면 service role 키 또는 `--backup` 모드.
   - 사진 다운로드 실패 → 노트에 `- 📷 … (다운로드 실패)`로 남고 다음 실행에 재시도(`photos_pending`). 급하면 `--no-photos`.
3. 정상 복귀 후 한 번 더 실행하면 멱등이라 중복이 생기지 않음. 🩺 Health의 `yk_id` 중복이 0인지 확인.

### 마커 블록을 실수로 지웠을 때
그냥 두세요. 다음 가져오기가 해당 섹션 헤더 아래에 블록을 다시 넣고, 헤더도 없으면 파일 끝에 1회 추가하고 로그에 남깁니다.

### 폴더/파일을 옮기고 싶을 때
Obsidian 안에서 옮기면 링크가 따라갑니다. 단 `10_오늘/YYYY/MM/`, `50_일기/YYYY/`, `30_할일/목록/`, `40_프로젝트/<이름>/` 구조는 importer 상수이므로 바꾸지 마세요. 앱에서 제목을 바꿔도 파일명은 유지되고 alias만 추가됩니다(`--rename-follow`로 바꿀 수 있음).

### 그래프 프리셋이 안 바뀔 때
그래프 뷰가 열려 있으면 Obsidian이 메모리 설정으로 `graph.json`을 덮어씁니다. 그래프 탭을 **닫고** `bash _System/Graph/graph_preset.sh <full|knowledge>` → 다시 열기.
