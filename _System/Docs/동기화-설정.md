# 🔄 여러 기기 동기화 — 어디서 열어도 같은 화면

> 맥북·아이폰·아이패드·데스크탑 어디서 열어도 **최신 볼트 그대로** 보이게 하는 설정.
> 원칙: **실시간 동기화는 Obsidian Sync**, **백업·자동화·Claude 채널은 맥북 한 대의 Git**. 둘은 같은 폴더에서 같이 돌아간다.

```
GitHub (joyunho/second-brain)
   ↑↓ git push / pull (Obsidian Git 플러그인, 10분마다 자동)      ← Claude가 정리한 결과·야간 import 결과도 이 길로 들어옴
맥북 = 원본 볼트 (git clone 한 폴더, Python 스크립트 실행 기기)
   ↕ Obsidian Sync (종단간 암호화, 몇 초 안에 전파)
아이폰 · 아이패드 · 데스크탑 = 같은 볼트, 같은 플러그인, 같은 그래프 설정
```

---

## 1. 맥북 (원본, 한 번만)

1. 저장소 받기 → 볼트로 열기 → 플러그인 설치 (README 6장).
   ```bash
   git clone -b claude/admiring-hawking-ogejlt https://github.com/joyunho/second-brain.git ~/second-brain
   ```
   **iCloud Drive 안에 두지 말 것.** `.git` 폴더가 iCloud와 충돌해 파일이 사라지거나 느려진다. `~/second-brain`처럼 로컬 경로에 둔다.
2. **Obsidian Git** (이미 설정됨: 10분마다 자동 pull·commit·push).
   - GitHub 인증: 터미널에서 한 번 `git push`가 되면 끝 (macOS 키체인이 기억). 안 되면 `brew install gh && gh auth login`.
   - 플러그인 설정에서 "Pull on startup"이 켜져 있는지 확인 → 옵시디언을 열 때마다 최신을 먼저 받는다.
3. **Obsidian Sync** 켜기: 설정 → Sync → 로그인 → **새 원격 볼트 만들기** → 연결.
   - 선택 동기화에서 전부 켜기: `설치된 커뮤니티 플러그인` · `커뮤니티 플러그인 설정` · `핵심 플러그인 설정` · `모양 설정` · `단축키`
     → 그래프 색(graph.json), 템플릿 설정, CSS 스니펫, Auto Note Mover 규칙이 전 기기에 똑같이 간다.
   - 동기화할 파일 형식: `이미지` · `PDF` 켜기 (YouKnow 사진, GoodNotes PDF).
   - 첫 업로드가 끝날 때까지(상태바 ✓) 기다린다.
4. 야간 자동화는 이 기기에서만: `crontab -e`
   ```
   30 23 * * * cd ~/second-brain && python3 -I _System/Scripts/import_youknow.py --supabase >> _System/Scripts/import.log 2>&1
   ```
   가져온 결과는 10분 안에 Obsidian Git이 푸시하고, Sync가 다른 기기로 보낸다.

## 2. 아이폰 · 아이패드 · 데스크탑 (기기마다 한 번)

1. Obsidian 설치 → 시작 화면 **Sync** → 로그인 → **원격 볼트에 연결** → 맥북에서 만든 볼트 선택.
2. 다운로드가 끝나면 설정 → 커뮤니티 플러그인 → **제한 모드 끄기** (기기별로 한 번. 플러그인 본체는 Sync가 이미 내려받았다).
3. **Obsidian Git은 이 기기들에서 끈다**: Obsidian Git 설정 → `Disable on this device`. Git은 맥북만 담당한다.
4. 설정 → 모양 → CSS 스니펫 → `brain-graph`가 켜져 있는지 확인.

## 3. 평소 흐름

| 어디서 썼나 | 어떻게 퍼지나 |
| --- | --- |
| 아이폰 옵시디언에서 일기 | Sync → 몇 초 안에 맥북·아이패드·데스크탑. 맥북 Obsidian Git이 10분 안에 GitHub 백업 |
| YouKnow 앱에서 할 일 | 밤 23:30 맥북 cron → 볼트 노트 생성 → Git 푸시 + Sync 전파 |
| Claude가 GitHub에 정리해 푸시 | 맥북 Obsidian Git이 10분 안에 pull → Sync로 전 기기 |
| 두 기기에서 같은 노트를 동시에 수정 | Sync가 병합. 어긋나면 설정 → Sync → **버전 기록**에서 복구 |

## 4. 주의

- **맥북의 옵시디언이 꺼져 있으면** Obsidian Git도 멈춘다. Claude의 변경·야간 import는 맥북에서 옵시디언을 다시 열 때 들어온다(Sync 자체는 영향 없음). 항상 켜 두고 싶으면 데스크탑을 "원본" 역할로 바꿔도 된다(1장을 데스크탑에서).
- Python 스크립트(`import_youknow.py`, `import_goodnotes.py`)는 **원본 기기에서만** 돈다. 휴대폰은 YouKnow 앱이나 옵시디언 모바일로 입력만.
- Sync 용량: 기본 플랜 1GB. YouKnow 사진을 많이 받으면 상위 플랜으로 올리거나 `--no-photos`로 사진을 빼고 가져온다.
- `.obsidian/workspace.json`(열린 탭 상태)은 git에서 제외되어 있다. 기기마다 다른 탭을 열어 두어도 충돌하지 않는다.

## 5. 유료가 싫다면 (대안)

| 방법 | 되는 기기 | 비고 |
| --- | --- | --- |
| **Remotely Save** 플러그인 + Dropbox/OneDrive/S3 | 전부 | 무료. 설정 파일까지 동기화하려면 플러그인 옵션에서 `.obsidian` 포함 켜기. Sync보다 충돌 처리가 단순함 |
| **iCloud Drive** | 애플 기기만 | 무료. 볼트를 iCloud에 두면 **git과 같이 쓸 수 없다** → GitHub 채널(Claude 정리·야간 import)은 별도 폴더에 clone 해 두고 결과를 수동 복사해야 함 |
| **Syncthing** | 맥·윈도우·안드로이드 | 무료·P2P. iOS는 Möbius Sync(유료 앱) 필요. 두 기기가 동시에 켜져 있어야 전파 |

가장 손이 안 가는 조합은 **Obsidian Sync + 맥북 Git**이다. 나머지는 전부 어딘가에서 수동 단계가 생긴다.
