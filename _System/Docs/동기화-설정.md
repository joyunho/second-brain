# 🔄 여러 기기 동기화 — 어디서 열어도 같은 화면, 무료로

> 맥북·아이폰·아이패드·데스크탑 어디서 열어도 **최신 볼트 그대로** 보이게 하는 설정.
> 볼트는 거의 텍스트라 몇십 MB다. 유료 Obsidian Sync(1GB 월 약 5,500원 / 10GB 월 약 11,000원)는 필요 없다.
> 원칙: **기기 간 실시간 동기화는 무료 클라우드**, **백업·자동화·Claude 채널은 맥북 한 대의 Git**. 둘은 같은 폴더에서 같이 돌아간다.

```
GitHub (joyunho/second-brain)
   ↑↓ git push / pull (Obsidian Git 플러그인, 10분마다 자동)   ← Claude가 정리한 결과·야간 YouKnow import도 이 길로
맥북 = 원본 볼트 (Python 스크립트를 돌리는 기기)
   ↕ iCloud Drive  또는  Remotely Save(OneDrive/Dropbox)
아이폰 · 아이패드 · 데스크탑 = 같은 볼트, 같은 플러그인, 같은 그래프 설정
```

어느 길인지 고르는 기준 하나: **기기가 전부 애플인가?**

| 기기 조합 | 방법 | 비용 |
| --- | --- | --- |
| 맥북 + 아이폰 + 아이패드 + 맥 데스크탑 | **A. iCloud Drive** | 0원 (5GB 무료. 이미 iCloud+ 쓰면 그대로) |
| 윈도우 데스크탑 또는 안드로이드가 섞임 | **B. Remotely Save + OneDrive** ← 선택 | 0원 (OneDrive 5GB 무료, Dropbox 2GB도 가능) |
| 돈 내도 되고 손 하나도 안 대고 싶음 | C. Obsidian Sync | 월 약 5,500원~ |

---

## A. iCloud Drive (애플 기기 전용, 무료)

옵시디언 iOS/iPadOS/macOS가 iCloud를 기본 지원한다. 플러그인 없이 된다. 단 **`.git` 폴더를 iCloud 안에 두면 안 된다**(수천 개 작은 파일이 충돌·evict됨). 그래서 git 저장소 본체는 홈 폴더에 두고, 볼트 안에는 그 위치를 가리키는 `.git` 파일 하나만 둔다.

### A-1. 맥북 (원본, 한 번만)
1. 맥에 Obsidian을 설치하고 한 번 실행한다 → iCloud에 `Obsidian` 폴더가 생긴다.
2. 터미널에서 볼트를 iCloud의 Obsidian 폴더에, git 저장소는 홈에 받는다:
   ```bash
   VAULT="$HOME/Library/Mobile Documents/iCloud~md~obsidian/Documents/second-brain"
   git clone --separate-git-dir="$HOME/.second-brain.git" \
     -b claude/admiring-hawking-ogejlt https://github.com/joyunho/second-brain.git "$VAULT"
   ```
   볼트 폴더 안의 `.git`은 한 줄짜리 파일(`gitdir: /Users/…/.second-brain.git`)이 된다. iCloud가 이 파일을 다른 기기에 복사해도 해가 없다.
3. 시스템 설정 → Apple ID → iCloud → iCloud Drive → **"Mac 저장 공간 최적화" 끄기** (git은 실제 파일이 필요하다). 또는 Finder에서 `Obsidian` 폴더 우클릭 → "지금 다운로드 유지".
4. Obsidian → "폴더를 볼트로 열기" → 위 `second-brain` 폴더 → 플러그인 설치 (README 6장).
5. **Obsidian Git** 플러그인: 이미 10분마다 자동 pull·commit·push 로 설정되어 있다. 터미널에서 `cd "$VAULT" && git push` 가 한 번 되면 키체인이 인증을 기억한다 (안 되면 `brew install gh && gh auth login`).
6. 야간 자동화 (`crontab -e`):
   ```
   30 23 * * * cd "$HOME/Library/Mobile Documents/iCloud~md~obsidian/Documents/second-brain" && python3 -I _System/Scripts/import_youknow.py --supabase >> _System/Scripts/import.log 2>&1
   ```

### A-2. 아이폰 · 아이패드
1. Obsidian 앱 설치 → "볼트 생성/열기" 화면에서 **"iCloud에 저장"** 을 켜면 iCloud `Obsidian` 폴더의 볼트 목록에 `second-brain`이 보인다 → 선택.
2. 설정 → 커뮤니티 플러그인 → **제한 모드 끄기** (플러그인 본체 `main.js`도 iCloud로 함께 왔으므로 설치 불필요).
3. Obsidian Git 설정 → **`Disable on this device`** (git은 맥북만).
4. 처음에는 iCloud가 파일을 내려받는 동안 노트가 비어 보일 수 있다. 몇 분 기다린다.

### A-3. 맥 데스크탑
같은 Apple ID로 로그인 → iCloud Drive 켜기 → Obsidian "폴더를 볼트로 열기" → `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/second-brain` → 제한 모드 끄기 → Obsidian Git `Disable on this device`.
(맥북 대신 이 데스크탑을 "원본"으로 삼아도 된다. 그러면 A-1을 여기서 하고 맥북은 A-3처럼 한다. 항상 켜져 있는 쪽이 원본에 유리하다.)

### A-4. iCloud 주의
- 두 기기에서 같은 노트를 **동시에** 고치면 iCloud가 `노트 2.md` 같은 사본을 만든다. 🩺 Health의 "깨진 링크"에 뜨면 합친다. 한 기기에서 쓰고 닫은 뒤 다른 기기를 여는 습관이면 거의 안 생긴다.
- 윈도우용 iCloud는 옵시디언과 궁합이 나쁘다. 윈도우가 있으면 B로.

## B. Remotely Save + OneDrive (기기 섞여 있을 때, 무료) ← 선택한 방법

모든 플랫폼(맥·윈도우·iOS·안드로이드)에서 같은 플러그인이 OneDrive와 볼트를 맞춘다. 컴퓨터에 OneDrive 앱을 깔 필요가 없다.
준비물: **개인용 Microsoft 계정** 하나(outlook.com / hotmail.com). 회사·학교 계정(OneDrive for Business)은 무료 기능으로 안 된다. 무료 5GB면 텍스트 볼트에 충분하다.

### B-1. 맥북 (원본, 처음 한 번)
1. 저장소 받기(iCloud 폴더 말고 홈 폴더) → 볼트 열기 → 플러그인 설치(README 6장):
   ```bash
   git clone -b claude/admiring-hawking-ogejlt https://github.com/joyunho/second-brain.git ~/second-brain
   ```
2. 커뮤니티 플러그인 → **Remotely Save** 설치 → 켜기.
3. Remotely Save 설정:
   | 항목 | 값 |
   | --- | --- |
   | Remote Service | `OneDrive (for personal)` → **Auth** → 브라우저에서 Microsoft 로그인 → "connected" |
   | Schedule for auto run | `every 5 minutes` |
   | Run once on startup | `10 seconds after startup` |
   | Advanced → **Sync config dir** | 켜기 — `.obsidian`(그래프 색·템플릿·플러그인 설정·플러그인 본체)이 전 기기에 간다 |
   | Advanced → **Sync underscore items** | **켜기** — 끄면 `_System`·`_Attachments`가 빠진다 |
   | Advanced → Ignore paths (있으면) | `^\.git` |
4. 리본의 동기화 아이콘(명령 팔레트 "Remotely Save: start sync") 한 번 → 첫 업로드 → 상태바 완료 표시까지 대기.
   OneDrive의 `Apps/remotely-save/second-brain`에 저장된다. 이 폴더는 OneDrive 쪽에서 이름을 바꾸거나 손대지 않는다.
5. **Obsidian Git**(찾아보기 이름은 'Git', 작성자 Vinzent)은 이 기기에서만 켜 둔다(10분마다 자동 pull·commit·push). 터미널에서 `cd ~/second-brain && git push`가 한 번 되면 키체인이 인증을 기억한다(안 되면 `brew install gh && gh auth login`).
6. 야간 자동화(`crontab -e`):
   ```
   30 23 * * * cd ~/second-brain && python3 -I _System/Scripts/import_youknow.py --supabase >> _System/Scripts/import.log 2>&1
   ```

### B-1′. OneDrive 로그인이 "Connecting to OneDrive…"에서 멈추면 → Dropbox로
최근 옵시디언에서 OneDrive 콜백이 다른 볼트 창으로 가는 버그가 있다(remotely-save #1142). 다른 볼트 창을 모두 닫고 Auth를 처음부터 다시 해도 안 되면 **Dropbox(무료 2GB)** 로 바꾼다. 콜백 대신 코드를 붙여넣는 방식이라 이 버그를 타지 않는다.
1. dropbox.com 무료 계정 → Remotely Save 설정 → Remote Service `Dropbox` → **Auth**
2. 모달의 링크로 브라우저 → 로그인 → 허용 → 화면의 **인증 코드** 복사 → 모달 입력칸에 붙여넣기 → 제출
3. `Sync config dir`·`Sync underscore items` 확인 → `Remotely Save: start sync`. 파일은 Dropbox `앱/remotely-save/second-brain`에 저장된다.
다른 기기도 같은 순서(같은 Dropbox 계정).

### B-2. 아이폰 · 아이패드 · 데스크탑 (기기마다 한 번)
1. 옵시디언 설치 → **새 볼트 만들기**, 이름은 정확히 `second-brain`(이름이 같아야 같은 창고를 본다. 다르면 설정의 Remote Base Directory를 `second-brain`으로).
2. 설정 → 커뮤니티 플러그인 → 제한 모드 끄기 → **Remotely Save** 설치 → 같은 Microsoft 계정으로 **Auth** → Advanced에서 **Sync config dir**·**Sync underscore items** 켜기.
3. 동기화 아이콘 한 번 → 노트·플러그인 본체가 내려온다 → 옵시디언을 **완전히 껐다 켜기** → 커뮤니티 플러그인에서 Templater·Dataview·Tasks 등이 켜져 있는지 확인(안 켜졌으면 토글).
4. **Obsidian Git** 설정 → `Disable on this device`.
5. 설정 → 모양 → CSS 스니펫 → `brain-graph` 확인.

### B-3. 평소
- 옵시디언을 **열면** 10초 뒤 자동 동기화, 열려 있는 동안 5분마다. 백그라운드에서는 돌지 않으니 폰에서 쓴 뒤 몇 초 두고 닫는다.
- 충돌 규칙은 "나중에 저장한 쪽이 이김". 같은 노트를 두 기기에서 동시에 고치지 않으면 된다. 중요한 글은 맥북 Git 히스토리에서 되살릴 수 있다.
- Remotely Save는 `.git`을 올리지 않는다(숨김 폴더). git은 맥북만.
- OneDrive 쪽 폴더를 직접 편집하지 않는다(플러그인이 메타데이터로 변경을 추적한다).

## 구글 드라이브는?

컴퓨터끼리만 된다. 휴대폰에서 막힌다.
- 맥·윈도우: "Google Drive for desktop"을 **미러 모드**로 두면 볼트를 그 안에 넣어도 된다(스트리밍 모드는 파일을 늦게 내려받아 옵시디언이 깨진다). git 저장소는 A-1처럼 드라이브 밖에.
- 아이폰·아이패드: 옵시디언 iOS는 볼트 위치로 "기기 내부"와 "iCloud"만 고를 수 있어 구글 드라이브 폴더를 못 연다. Remotely Save의 구글 드라이브 연결은 유료 PRO 기능.
- 안드로이드: 드라이브 앱이 폴더를 기기로 내려받지 않아 별도 동기화 앱이 필요하다. 그럴 바엔 B가 단순하다.
→ 휴대폰까지 무료로 묶으려면 A(iCloud) 또는 B(OneDrive/Dropbox)다.

## C. Obsidian Sync (유료)
설정 → Sync → 로그인 → 새 원격 볼트 → 선택 동기화 전부 켜기 → 다른 기기에서 "원격 볼트에 연결". 손은 제일 안 가지만 월 5,500원(1GB)~11,000원(10GB). 사진을 빼면(`--no-photos`) 1GB로도 몇 년은 간다.

## 평소 흐름 (A·B 공통)

| 어디서 썼나 | 어떻게 퍼지나 |
| --- | --- |
| 아이폰 옵시디언에서 일기 | 클라우드 → 몇 초~몇 분 안에 다른 기기. 맥북 Obsidian Git이 10분 안에 GitHub 백업 |
| YouKnow 앱에서 할 일 | 밤 23:30 맥북 cron → 볼트 노트 생성 → Git 푸시 + 클라우드 전파 |
| Claude가 GitHub에 정리해 푸시 | 맥북 Obsidian Git이 10분 안에 pull → 클라우드로 전 기기 |

- **맥북의 옵시디언이 꺼져 있으면** GitHub 쪽 변경(Claude·야간 import)은 다음에 열 때 들어온다. 기기 간 동기화는 영향 없음.
- Python 스크립트는 원본 기기에서만 돈다. 휴대폰은 YouKnow 앱이나 옵시디언 모바일로 입력만.
- `.obsidian/workspace.json`(열린 탭)은 git에서 제외. 기기마다 다른 탭을 열어 둬도 충돌하지 않는다.
