# ⚡ 빠른 입력 문법 — 치트시트

> `Ctrl/Cmd+N` → **⚡ 빠른 입력** → 여러 줄을 한 번에 붙여 넣으면 `capture.js`가 줄마다 **할 일 · 계획 · 습관 · 일과 · 프로젝트**로 나눠 각 폴더에 씁니다. 규칙은 YouKnow 앱의 "빠른 입력"과 **정규식까지 같아서**, 앱에 치든 옵시디언에 치든 결과가 같습니다(선택적 `PUSH_TO_YOUKNOW`가 이 전제 위에서 동작).
> 아래 예시의 결과는 전부 `node _System/Scripts/tests/capture.test.js`가 앱 원본 코드를 오라클로 삼아 검증하는 값입니다. 기준일은 2026-10-16(금)입니다.

## 0. 한눈에

```
내일 오후 3시 치과                 → 🗓️ 계획   2026-10-17 15:00–16:00
매주 월수금 저녁 7시 헬스          → 🔄 일과   월·수·금 19:00–20:00 (요일 노트 3개에 한 행씩)
매일 영어 단어 20개                → 🔁 습관   60_습관/영어 단어 20개.md
프로젝트: 유튜브 채널 개편         → 🗂️ 프로젝트 40_프로젝트/유튜브 채널 개편/
- 9/10까지 영상 편집!!             → ✅ 할 일   마감 2027-09-10 · 중요(4) · 프로젝트 = 유튜브 채널 개편
- 썸네일 만들기 그리고 자막 넣기   → ✅ 할 일   (한 덩어리 — 날짜/시간 토큰이 없어 '그리고'로 안 나뉨)
언젠가 책 정리 #집                 → ✅ 할 일   언젠가(1) · 프로젝트 "집"(없으면 생성)
주말마다 러닝                      → 🔄 일과   토·일 09:00–10:00 + "시간을 안 적어서 09:00으로 넣었어요."
```

## 1. 무엇이 무엇이 되나 (판정 순서)

한 줄에서 **우선순위 → 프로젝트 마커 → 반복 → 날짜 → 시간**을 차례로 뽑아낸 뒤, 남은 글자가 제목이 됩니다. 종류는 위에서부터 첫 일치:

| 순서 | 조건 | 종류 | 볼트에서 생기는 것 |
| --- | --- | --- | --- |
| 1 | 날짜·우선순위만 있고 제목이 없음 (`내일`, `긴급`) | **헤더 줄** | 아무것도 안 만들고, 아래 줄들의 기본 날짜/우선순위가 됨 |
| 2 | `프로젝트:`/`PJ:` 접두, 알려진 프로젝트 이름 단독, 마커만 있는 줄(`#집`) | 🗂️ **프로젝트** | `40_프로젝트/<이름>/<이름>.md` (status 진행 중, area 개인). 날짜가 있으면 `due` |
| 3 | 요일 목록 (`매주 월수금`, `화목마다`, `주말마다`, `평일`) | 🔄 **일과** | `20_일정/일과/<요일>요일.md` 일과표에 요일마다 한 행 (마커 없음 = 내 소유) |
| 4 | `매일`, `N일마다`, `1일 1X`, 요일 없는 `매주` | 🔁 **습관** | `60_습관/<이름>.md` (시간은 버림) |
| 5 | 단일 시각 + `까지`/`마감` (`5시까지 보고서`) | ✅ **할 일** | 마감 = 날짜 또는 오늘, 세부 메모 `17:00까지` |
| 6 | 시각이 있음 (`3시 회의`, `7-10시 공부`) | 🗓️ **계획** | 그 날짜(기본 오늘) 일간 노트 `### 하루 계획` 블록 **뒤**에 `- ⬜ HH:MM–HH:MM 제목` |
| 7 | 그 외 전부 | ✅ **할 일** | `30_할일/목록/<제목>.md` — status 진행 전, start 오늘, `yk_pending: true` |

- 계획에는 프로젝트가 붙지 않습니다(`내일 오후 3시 치과 #병원` → 계획 "치과". 파서는 `project: "병원"`을 돌려주지만 계획 줄에는 쓰지 않음 — 앱 `day_plans`에 프로젝트 열이 없는 것과 동일).
- 우선순위는 **할 일에만** 저장됩니다. 계획·습관·일과·프로젝트에 `!!`를 붙여도 무시.
- 계획 제목이 60_습관/20_일정 노트 제목과 정확히 같으면 `[[제목]]`으로 링크됩니다.

## 2. 날짜

가장 **앞쪽에서 매칭된** 표현 하나가 이깁니다. 매칭된 글자(와 뒤의 `까지/에/부터/쯤/경`)는 제목에서 지워집니다.

| 적는 법 | 뜻 (2026-10-16 금 기준) |
| --- | --- |
| `오늘` `내일` `낼` `모레` `낼모레` `글피` | 10-16 · 10-17 · 10-17 · 10-18 · 10-18 · 10-19 |
| `3일 뒤` `이틀 후` `2주 뒤` `일주일 뒤` `한 달 뒤` | +N일(하루·이틀·사흘·나흘·닷새·열흘) · +7N · 같은 날 N달 뒤 |
| `10월 25일` `10/25` `10.25` | 그 날짜. **지났으면 내년**(`9/10` → 2027-09-10) |
| `25일` (월 없이) | 오늘 이후 첫 25일 |
| `11월 초` `11월 중순` `11월 말` · `11월` 단독 | 5일 · 15일 · 말일 · 말일 |
| `이번 달 20일` `이번 달 말` `월말` `말일` | 10-20 · 10-31 |
| `다음 달 5일` `다음 달 초/중순/말` | 11-05 · 11-05 / 11-15 / 11-30 |
| `연말` `올해 안에` | 12-31 |
| `내년 3월 1일` `내년 3월` `내년 초` `내년` | 2027-03-01 · 2027-03-31 · 2027-01-15 · 2027-12-31 |
| `금요일` `이번 주 금요일` | 그 요일. 오늘이면 오늘, **지났으면 다음 주로**(절대 과거 안 됨) |
| `다음 주 수요일` `다다음 주 수요일` | 월요일 시작 기준 다음 주 10-21 · 다다음 주 10-28 |
| `다음 주` 단독 → 월요일 · `다음 주까지` → 일요일 | 10-19 · 10-25 |
| `이번 주` `이번 주까지` → 일요일 · `주말` → 토요일 | 10-18 · 10-17 |
| `11월 둘째 주 화요일` `11월 마지막 주 금요일` | 그 달의 n번째 요일 |
| `2026-11-01` `2026.11.01` `2026년 11월 1일` `26년 11월 1일` | 그대로 |
| `10/20~10/22` | 범위는 앞 날짜만 값으로, 뒤 날짜는 제목에서만 지움 |
| 영어 `tomorrow` `next week` `jan 5` `mon` `by/until/due …` | 한국어로 바꾼 뒤 같은 규칙 |

날짜 뒤에 `까지|마감|이내|안에|내로|내에`가 붙으면 "마감" 표시지만, 할 일의 `due`는 어차피 그 날짜라 결과는 같습니다. 날짜가 없는 할 일은 `due` 없음(`start`만 오늘).

## 3. 시간

| 적는 법 | 결과 |
| --- | --- |
| `오후 3시` `15시` `3:30` `저녁 7시 반` | 15:00 · 15:00 · 03:30(`:`가 있으면 오전/오후 추론 없이 적힌 그대로 — 오후면 `15:30`) · 19:30 |
| `오전/아침/새벽 H시` → 오전 · `오후/저녁/밤/낮 H시` → 오후 | `밤 12시`·`새벽 12시`·`오전 12시` = 00:00 · `밤 1~5시`는 새벽 그대로 |
| 말 없이 `3시` | 1~4시 → **오후**(안내: "오후로 해석했어요. 새벽이면 시간을 고쳐주세요.") |
| 말 없이 `5시` `6시` | 아침 단어(기상·출근·헬스·운동·러닝·스트레칭·수업…)가 있으면 오전, 아니면 오후 |
| 말 없이 `7시`~`12시` | 적힌 그대로. 단 저녁·여가 단어(게임·맥주·회식·영화·넷플·퇴근·야근·치맥·술·데이트…)가 있으면 1~11시를 오후로 |
| 단일 시각 | 계획 끝 = 시작 **+1시간** |
| `7-10시` `9시~11시` `오후 2시부터 4시까지` | 범위 → **항상 계획**(끝에 `까지`가 있어도 마감 아님) |
| `5시까지 보고서` `오후 3시 마감 제출` | 단일 시각 + 까지/마감 → **할 일** + 세부 메모 `17:00까지` |
| `열두시` `한시 반` `정오` `자정` | 12시 · 1:30 · 낮 12시 · 밤 12시로 바꾼 뒤 처리 |
| `3pm` `9-10am` | `오후 3시` · `오전 9시~오전 10시` |

## 4. 우선순위 (할 일에만)

| 적는 법 | priority | 라벨 | Tasks 줄 |
| --- | --- | --- | --- |
| `!!!` `긴급` `급함` `급해` `급한` `당장` | 5 | 긴급 | 🔺 |
| `!!` `중요` `높음` · 단일 `!` | 4 | 중요 | ⏫ |
| (없음) | 3 | 보통 | — |
| `낮음` `여유` | 2 | 낮음 | 🔽 |
| `언젠가` `언젠간` `나중에` | 1 | 언젠가 | ⏬ |

마커는 제목에서 지워집니다(`세금 신고!!!` → "세금 신고"). 헤더 줄 `긴급` 아래의 할 일들은 전부 5가 됩니다(줄에 자기 우선순위가 있으면 그게 우선).

## 5. 프로젝트

| 적는 법 | 결과 |
| --- | --- |
| `#이사준비 박스 사기` `@이사준비 …` `[이사 준비] …` | 할 일, 프로젝트 = 마커 이름. 없는 프로젝트면 **새로 만듦** |
| `#이사준비` (마커만) | 프로젝트 자체 |
| `프로젝트: 이사 준비` `PJ: 이사 준비` | 프로젝트. 날짜가 있으면 `due` |
| `이사 준비 프로젝트` (접미) | 프로젝트 (제목은 적은 그대로) |
| `이사 준비` — 이미 있는 프로젝트 이름 단독 | 프로젝트(기존) |
| `이사 준비 견적 비교` — 이미 있는 이름이 문장 안에 | 할 일 "견적 비교", 프로젝트 = 이사 준비 (`…의/에서/관련` 조사도 처리) |
| 프로젝트 줄 아래 `- ` 불릿 줄 | 그 프로젝트의 할 일/계획(불릿 없는 줄이 나오면 상속 끝) |

## 6. 반복

| 적는 법 | 종류 | 결과 |
| --- | --- | --- |
| `매일 물 2리터` `맨날 …` `날마다 …` | 🔁 습관 | 시간이 있어도 버림("매일 하는 일이라 습관으로 넣었어요(시간은 뺐어요).") |
| `3일마다 화분 물주기` | 🔁 습관 | 안내 "3일마다 — 습관으로 넣었어요." (간격은 저장 안 됨) |
| `1일 1커밋` | 🔁 습관 | 제목 그대로 |
| `매주 독서 모임` (요일 없음) | 🔁 습관 | "요일을 안 적어서 습관으로 넣었어요. 요일이 있으면 일과로 바꿔주세요." |
| `매주 화요일 오후 8시 영어 회화` | 🔄 일과 | 화요일 20:00–21:00 |
| `매주 월수금 저녁 7시 헬스` `매주 월·수요일 …` | 🔄 일과 | 요일마다 한 행 |
| `화목마다 수영` `월요일마다 …` | 🔄 일과 | 화·목 09:00–10:00 + 시간 안내 |
| `주말마다 러닝` | 🔄 일과 | 토·일 |
| `평일 7시 기상 스트레칭` | 🔄 일과 | 월~금 07:00–08:00 |
| 영어 `every day` `every monday` `weekly` | → `매일` `매주 월요일` `매주 ` | 위 규칙 |

일과에 시간이 없으면 09:00–10:00이 들어가고 "시간을 안 적어서 09:00으로 넣었어요." 안내가 뜹니다. 월간·연간 반복은 없습니다.

## 7. 여러 줄 · 헤더 · 불릿 · 쉼표

| 적는 법 | 결과 |
| --- | --- |
| 줄바꿈 | 줄마다 항목 하나 |
| `- ` `* ` `• ` `1. ` `[ ] ` 접두 | 지우고 "불릿 줄"로 기억(프로젝트 상속에 쓰임) |
| `- [x] 끝난 일` | **버림**(이미 끝난 체크박스) |
| `내일` 한 줄 → 아래 `- 세탁소` `- 은행` | 헤더 줄: 둘 다 마감 내일인 할 일 |
| `긴급` 한 줄 → 아래 줄들 | 둘 다 우선순위 5 |
| `프로젝트: 이사 준비` → `- 박스 사기` → `- 11/1까지 견적 비교` → `청소기 돌리기` | 프로젝트 1 + 그 프로젝트 할 일 2 + 프로젝트 없는 할 일 1(불릿이 없어서) |
| `내일 3시 치과, 5시 약국` | 쉼표 분리 → 계획 2개, 둘 다 내일(첫 조각의 날짜를 같은 줄 조각들이 물려받음) |
| `내일 3시 치과 그리고 모레 5시 약국` | `그리고`/`/`/`;`로도 분리 — 단 **조각 2개 이상에 날짜·시간·#태그 토큰이 있을 때만** |
| `우유, 계란, 빵` | 토큰이 없어 **한 항목** "우유, 계란, 빵" |
| `썸네일 만들기 그리고 자막 넣기` | 한 항목 |

헤더 줄은 프로젝트 상속을 끊습니다 — 프로젝트 줄과 그 불릿들 사이에 `중요` 같은 헤더를 끼우지 말고, 헤더를 **먼저** 적으세요.

## 8. 실행 후 볼트에서 일어나는 일

1. 미리보기 메뉴: `N개로 나눴어요 · 모두 추가` / 항목 하나만 선택 / 취소. 안내문(해석 힌트)은 Notice로 뜹니다.
2. **할 일** → `30_할일/목록/<제목>.md`(tpl-task 형식: `status: 진행 전`, `priority`, `priority_label`, `start` 오늘, `due`/`마감`, `project` 링크, `yk_pending: true`, Tasks 줄 `- [ ] 제목 ⏫ 🛫 시작 📅 마감`, 구글 캘린더 링크). 프로젝트가 없으면 먼저 만듭니다. 같은 제목이 있으면 ` (2)`.
3. **계획** → 그 날짜의 `10_오늘/YYYY/MM/YYYY-MM-DD.md`(없으면 tpl-daily로 생성) `%% yk:plans:end %%` 바로 뒤에 `- ⬜ 15:00–16:00 치과`. 마커 없는 줄 = 내 소유, importer가 보존.
4. **습관** → `60_습관/<이름>.md`(tpl-habit, `tags: [hub]`). 이미 있으면 그대로.
5. **일과** → `20_일정/일과/<요일>요일.md`(없으면 tpl-routine으로 생성) 일과표 `%% yk:routines:end %%` 바로 뒤에 `| 19:00 | 20:00 | 헬스 | 초록 | |` 행(마커 없음 = 내 소유). 색은 앱처럼 현재 행 수로 자동 배정(팔레트 `(n+4)%8`), 끝 시간이 없으면 `—`. 제목이 60_습관 노트와 같으면 `[[헬스]]`.
6. **프로젝트** → `40_프로젝트/<이름>/<이름>.md`(tpl-project, status 진행 중 · area 개인 · 날짜가 있으면 `due`는 직접 채워야 함). `자료/` 폴더는 라우터 12번으로 첫 자료를 넣을 때 생깁니다.
7. `PUSH_TO_YOUKNOW = true`(tpl-inbox.md 상단)면 미리보기에서 **고른 항목**을 앱 `POST /api/capture`에도 보냅니다(모두 추가 = 원문 그대로, 하나만 = 그 항목을 혼자서도 같은 뜻이 되게 다시 적어서). 실패하면 노트에 `yk_dirty: true`. 야간 importer가 (title, due, created ±1일)로 채택해 `yk_id`를 채우고 `yk_pending`을 지웁니다.

## 9. 같은 파서를 쓰는 다른 곳

- 라우터 2번 **✅ 할 일 (한 개)** 의 "마감" 질문, 4번 📔 일기의 "날짜" 질문, 🗂️ 프로젝트의 "마감" 질문: `capture.parseDate("다음주 수요일까지 보고서", 오늘)` → `{ date: "2026-10-21", rest: "보고서" }`. (`어제`·`그제`는 `parseDate`가 모르는 표현이라 `tpl-inbox`가 직접 처리합니다 — 일기 날짜용.)
- iOS 단축어 "뇌에 추가"(Advanced URI): URL의 `data`는 `<%* tR += await tp.file.include("[[tpl-inbox]]") %>` 줄 + 줄바꿈 + 텍스트(URL 인코딩; README 3-6). Templater 폴더 템플릿은 빈 파일에만 붙으므로 이 명령 줄이 tpl-inbox를 실행시키고, 파일명이 `빠른입력`으로 시작하면 메뉴 없이 본문을 이 문법으로 바로 분배.
- 폰의 YouKnow 앱 빠른 입력·Siri `/api/capture`: 같은 규칙(앱 원본). 밤에 importer가 가져옵니다.
